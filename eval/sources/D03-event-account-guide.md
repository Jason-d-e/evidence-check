# DemoClub event account guide

Version 1, effective 2026-11-03. DemoClub is fictional.

## reset

A DemoClub event-account password reset link expires after 30 minutes. At most three password-reset requests are allowed in one hour. If a link expires, request a new one. Support never asks users to send their current password.

## access

The workshop joining link is included in the confirmation email. A confirmed participant who cannot find the email should check the spam folder and then contact support. The workshop joining link is not published in this knowledge base.
