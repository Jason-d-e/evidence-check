# DemoClub support guide

Version 1, effective 2026-11-03. DemoClub is fictional.

## contact

The fictional support address is help@democlub.invalid. Support hours are Monday to Friday, 10:00 to 18:00 MYT. The target first response time is two business days. There is no live-chat service or guaranteed immediate response.

## request

A support request should contain the event name, a description of the problem, and a screenshot with private information removed if useful. Never send passwords, API keys or private identity documents.

## cancellation

To cancel an Intro to AI Tools workshop registration, reply to the confirmation email before 11 November 2026 at 18:00 MYT. Cancellation releases a place to the waiting list. Transfers to a different person are not supported.
